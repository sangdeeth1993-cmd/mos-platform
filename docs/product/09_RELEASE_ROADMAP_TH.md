# 09 — Release Roadmap

## Milestone 1 — Product Foundation

Deliverables:
- Vision
- PRD
- Roles & Permission
- Module Map
- Workflows
- Architecture
- Data Model
- Design System

Exit criteria: ผู้บริหารอนุมัติ Scope ของ MVP

## Milestone 2 — Identity & Organization

- Supabase migration baseline
- Authentication
- Profiles
- Companies / Departments
- Roles and RLS
- Admin user management

Exit criteria: ผู้ใช้ Pilot Login และเห็นข้อมูลตาม Scope

## Milestone 3 — Project & Task Core

- Projects
- Project members
- Tasks
- Updates / Comments
- Review workflow
- Attachments basic

Exit criteria: ทีม Pilot ใช้ MOS เป็นช่องทางหลักสำหรับงานใหม่

## Milestone 4 — Dashboard & Notifications

- Employee Home
- Manager Dashboard
- Executive Portfolio
- Notification rules
- Overdue escalation

Exit criteria: รายงานสถานะประจำสัปดาห์ดึงจาก MOS ได้

## Milestone 5 — Pilot Hardening

- Security test
- Performance fixes
- Backup / recovery procedure
- User training
- SOP
- 30-day pilot

Exit criteria: Go/No-Go สำหรับ Production rollout

## Future Releases

- Meetings / Minutes
- Approval
- Risk / Issue
- Documents / Knowledge
- KPI / OKR
- AI summaries and recommendations
