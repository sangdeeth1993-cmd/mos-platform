# MOS Platform v1.2

Company Operating System built with Next.js and Supabase.

## Current modules
- Authentication and protected routes
- Organization, departments and profiles
- Project Management: projects, members, milestones, activity and RLS

## Install Milestone 3
See `docs/MILESTONE_3_SETUP_TH.md`.

## Environment variables
Copy `.env.example` to `.env.local` for local development. Configure the same values in Vercel.

## Commands
```bash
npm install
npm run dev
npm run typecheck
npm run build
```
